# Orbital Drift: Meteor

**Orbital Drift: Meteor** is a small 3D gameplay prototype created in **Unity and C#**.

The prototype features a single planet and a single player-controlled car. Meteors spawn above the planet and fall toward its surface, creating a simple survival challenge for the player.

The main purpose of this project was to experiment with **Unity physics, player movement, meteor spawning, collision detection, visual effects, and basic game-state systems**.

## 🎮 Prototype Gameplay

The player drives a car around a small spherical planet while trying to avoid falling meteors.

The prototype currently contains:

* One playable planet
* One player-controlled car
* Meteor spawning system
* Meteor movement toward the planet
* Collision detection
* Meteor explosion effect
* Planet crater effect
* Basic score system
* Game-over system
* Restart functionality

## 🛠️ Built With

* **Unity**
* **C#**
* Unity Physics
* Unity UI
* Prefabs
* Particle/Visual Effects

## 🧠 What I Learned

This project helped me practice several fundamental Unity development concepts, including:

* Working with Rigidbody and physics
* Creating player movement
* Instantiating and managing prefabs
* Creating a meteor spawning system
* Detecting collisions
* Creating basic gameplay effects
* Managing score and game states
* Connecting multiple C# scripts to create a playable game loop

A key part of the prototype was experimenting with movement and object interactions on a **spherical planet**, rather than a traditional flat level.

## 📌 Project Status

**Prototype / Learning Project**

This is not intended to be a full commercial game. It was created as a small gameplay experiment while learning Unity and C# game development.
